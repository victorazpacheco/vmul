VMUL

Victor MarkUp Language — a simple language that compiles to HTML.

VMUL uses commands beginning with $, HTML tags represented with @, and text substitutions such as *, #, _, and %.

StartUnique $ Tags@ HTML TagsCombining TagsTextFull ExampleCompiler

How it works

The compiler reads a .vmul file, performs the substitutions defined in replace(), and writes the resulting HTML to an output file.

python vmul.py
Flow: file.vmul → replace() → index.html

These are VMUL-specific commands. They are replaced directly with HTML or with pieces used to build an HTML tag.

HTML tags with @ syntax

The @ prefix represents an HTML tag name. It is normally combined with $OPENTAG and $CLOSETAG.

@HTML → html
@HEAD → head
@TITLE → title
@BODY → body
@H1 → h1
@H2 → h2
@B → b
@I → i
@IMG → img
@BUTTON → button
@SPAN → span
@EM → em
@VAR → var

Combining tags

VMUL can build HTML by combining small commands together.

Image example

$OPENTAG@IMG $SRC$HTTPSexample.com/image/$CLOSETAG

Output:

<img src="https://example.com/image/">

HTML title example

$OPENTAG@TITLE$CLOSETAGMy VMUL Site$OPENENDTAG@TITLE$CLOSETAG

Output:

<title>My VMUL Site</title>

Button with an ID

$OPENTAG@BUTTON $IDmyButton$ENDATTRIBUTES$CLOSETAGClick here$OPENENDTAG@BUTTON$CLOSETAG

Output:

<button id="myButton">Click here</button>

Text formatting

_text_<u>text</u>

Escaping: use a backslash to make a closing delimiter literal instead of interpreting it, such as \*, \#, \_, \-, or \!.

Current compiler

This documentation is based directly on the supplied replace() function. The compiler performs string replacements in sequence.

Input

file.vmul

Default output

index.html

If the input fields are left empty, the program uses file.vmul as input and index.html as output.

Important: $HEIGHT currently becomes width=", not height=". This page documents the actual behavior of the supplied compiler.
