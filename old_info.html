Commands in VMUL and what's translated in HTML:

  • # -> h1

  • ## -> h2

  • * -> i

  • ** -> b

  • ! -> title

  • % -> var

  • _ -> u

  • - -> s


  • $\n -> br
    • br>
  • $FULLBAR -> meter value = "1"

  • $SEMIBAR -> meter value = "0.5"

  • $ZEROBAR -> meter value = "0"

  • $HASTAG -> #

  • $DOUBLEHASTAG -> ##

  • $EXCLAMATIONMARK -> !

  • $ASTERISK -> *

  • $DOUBLEASTERISK -> **

  • $UNDERLINE -> _

  • $HYPHEN -> -


Other rules:
Closing tags uses "\". Example:

  • \! -> /title

  • \# -> /h1


    • You also can use @ + html name tag to type what you want. Example:


  • @H1 -> h1 (not the tag, literaly only h1)

  • \@H2 -> /h2 (also)
